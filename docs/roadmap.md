# Development Roadmap

## Milestone 0: Architecture Approval

- Confirm product principles.
- Review module boundaries.
- Approve MVP DocType specifications.
- Confirm permission and visibility assumptions.

## Milestone 1: Core Timeline MVP

- Implement Timeline Event, Activity Type, Reaction Type, Reaction, and ProgressOS Settings.
- Add generic document reference support.
- Add basic unit tests for event creation, validation, and reactions.

## Milestone 2: Feed Experience

- Add ProgressOS workspace.
- Add list filters for recent activity, my activity, team activity, mentions, needs attention, recognition, and recent wins.
- Optimize quick event capture.

## Milestone 3: Extensibility

- Publish stable hook events.
- Add API documentation.
- Add integration tests for external event creation and reactions.

## Milestone 4: Intelligence Foundation

- Add provider-independent AI adapter interfaces.
- Add summary generation as an optional configured feature.
- Keep semantic search and advanced trend detection out of scope until timeline data quality is proven.
