# UI Wireframes

## Workspace

ProgressOS workspace sections:

- Recent Activity
- My Activity
- Team Activity
- Mentions
- Needs Attention
- Recognition
- Recent Wins
- Configuration

## Quick Event Capture

The default capture pattern should require:

1. One click to open quick entry.
2. One dropdown to choose an activity type.
3. One text box for the event description.

Optional fields should stay collapsed unless needed.

## Feed Card

A feed card should show:

- Activity type icon and label.
- Event title or generated summary.
- Author and event datetime.
- Description preview.
- Linked documents.
- Comments, reactions, and next action indicators.

## Reference Timeline

Any supported document should be able to show a related timeline panel with events attached through generic references.
